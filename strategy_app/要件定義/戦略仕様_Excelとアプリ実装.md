# もて耐 レース戦略 — 仕様書（元Excel × アプリ実装）

*作成: 2026-07 / 対象アプリ: `strategy_app/strategy-app`（Phase 1・2 実装時点）*

このドキュメントは、
1. **元になった Excel `lap管理`（`2023 もて耐ラップ管理_01.xlsm`）に書かれていた戦略の内容**
2. **今回アプリで実装した戦略作成ロジック**

を対応づけてまとめたもの。「レース中に何を入力し、何を計算し、どう判断するか」の正本。

---

## 0. 前提（レースの性質）

- 対象: **もて耐**（ツインリンクもてぎ／バイク耐久レース）
- **時間制耐久**: レース時間 **420分**（周回数固定ではなく、時間内に何周回れるかを競う）
- コース長: **4.801379 km**
- 走者: 複数ドライバーが交代（2023実績は Uchida / Hideto / Fukuoka / Yoshinaga）
- レース中は **1周ごとにラップタイムを手入力**し、燃料・ピット・ペースをリアルタイム管理する

戦略の核心はただ1つ:

> **「今の給油量であと何周走れるか（可能Lap数）」と「残り時間で何周・何回ピットに入れるか」を常に把握し、ピットのタイミングとドライバー交代を最適化する。**

## 1. 元Excel `lap管理` の内容

Excel は **3シート**構成。

| シート | 役割 |
|---|---|
| **実績** | レース中に1周ずつ手入力する本番シート。燃料・ピット・平均ペースを即時計算 |
| **計画** | 実績と同じ構造の「予定」。計画 vs 実績の比較に使う |
| **燃料消費量** | ラップタイム→ドライバー別燃費の変換表＋ケース別燃料＋天候メタ |

### 1-1. 「実績」シート

#### (a) レース設定ブロック（左上）
レース全体のパラメータと集計。

| 項目 | 例（2023） | 意味 |
|---|---|---|
| 周回数 | 154 | 走破した通算周回 |
| 総積算時間 | 422分3.97秒 | 経過時間 |
| 残り時間 | −2分 | レース終了までの残り |
| レース時間 / コース距離 | 420分 / 4.801379km | レース設定 |
| TL平均タイム | ドライ | 目標ラップの基準路面 |
| （ドライバー別平均） | Uchida 2:24.34 / Fukuoka 2:25.71 / Yoshinaga 2:27.71 / Hideto | 各走者の平均ラップ |
| 想定Lapタイム | 2:26 | 通常周の想定 |
| 想定OUT-Lapタイム | 2:40 | ピット後アウト周の想定 |
| 想定IN-Lapタイム | 2:20 | ピットイン周の想定 |
| 想定ウェットLapタイム | 2:50 | 雨天時の想定 |
| 想定SCタイム | 4:20 | セーフティカー時の想定 |
| 想定Pitタイム | 240秒 | 1回のピットロス |
| 以降想定ウェット周回 / SC周回 | 0 / 0 | 残りで見込む雨・SC周回 |
| MAX ST周回数 | 15 | 1スティントの最大周回 |
| 設定周回数/ST | 20 | 1スティントの狙い周回 |
| 残り可能周回数 | — | 残り時間×ペースの見込み |
| 残りPit回数（＝残りST数） | — | 残りのピット回数 |
| 最終ST周回数 | 12 | 最後のスティントの周回 |

#### (b) スティントブロック（最大12・各ドライバー割当）
「スティント」＝**給油から次の給油までの連続走行区間**。各ブロックの上部に集計、下部にラップ明細テーブル。

**集計行:**
| 行 | 内容 |
|---|---|
| 積算走行時間 | そのスティントの走行時間 |
| ドライTL平均タイム / 周回数 | ドライ路面の平均ラップと周回数 |
| ウェットTL平均タイム / 周回数 | ウェットの平均と周回数 |
| SCTL平均タイム / 周回数 | SC中の平均と周回数 |
| 総平均タイム / 予定(Laps) | 全体平均と予定周回 |
| 3周平均タイム / 残り(Laps) | 直近3周平均（今のペース）と残り周回 |

**燃料行:** 想定燃費km/L、消費量L/Lap、OUT/IN消費量L、実測残ガスL、路面別（D/W/SC/EX1/EX2）、燃料消費量L、スタート後消費量L、スタート後走行距離km、実燃費km/L。

**ラップ明細テーブル（1周1行）:**
| 列 | 内容 |
|---|---|
| Lap | スティント内の周番号 |
| OUT/IN | ピットアウト周 / ピットイン周 / 通常（空欄） |
| D/W/SC/EX1/EX2 | 路面コンディション（ドライ/ウェット/SC/特殊1/特殊2） |
| タイム | **「分」列＋「秒」列**。秒は `27.651` のように **1/1000秒精度** |
| ガス使用量L | その周の燃料使用量 |
| 残ガスL | 走行後の残燃料 |
| 可能Lap数 | **残ガス ÷ 1周消費量 = あと何周走れるか** |

> ⚠️ アプリで「0.0何秒が入力できない」と言っていた箇所は、この**秒列（1/1000秒）**に相当する。

### 1-2. 「計画」シート
実績と**まったく同じ構造の「予定」版**。想定タイム・想定燃料で先の展開を組み、実績と突き合わせて「予定より速い/遅い」を見る。

### 1-3. 「燃料消費量」シート
- **ラップタイム→燃費 変換表**: ラップタイム（秒 135〜180、0.5刻み）ごとに、ドライバー別の消費量（L/周）を DRY / WET 別に定義。
  → ただし**実データは全域フラット**（DRY=0.35、WET=0.32）。実運用は「路面別の定数消費」だった。
- **ケース別燃料（L）**: DRY-OUTLAP 0.33 / DRY-INLAP 0.33 / WET-OUTLAP 0.30 / WET-INLAP 0.30 / SC 0.27 / EX1 / EX2
- **天候メタ**: Weather / Temp / Humidity / Atmosphere / DATE（DRY・WET 2ケース）

### 1-4. 運用メモ（ルートの README より）
- 出走前チェック: 時刻合わせ、tire空気圧、ガソリン容量、パッド厚、ブレーキフルード、オイル
- **ピット滞在時間**: ピット内走行20秒 → 4分 − 20秒 = **3分40秒が滞在**。**3分30秒でペナルティ実績あり**
- setting: ギア比 rear sprocket 41T（'23純正から1Tロング）

## 2. 今回アプリで実装した戦略作成ロジック

### 2-1. データモデル（Prisma / SQLite）

| モデル | 対応するExcelの概念 | 主なフィールド |
|---|---|---|
| **RaceConfig** | レース設定ブロック | raceDurationMin(420), courseLengthKm, tankCapacityL, startFuelL, pitLossSec(240), maxStintLap(15), 路面別燃費(Dry/Wet/SC/OutIn), 想定タイム(Lap/OUT/IN/Wet/SC), startedAt |
| **Rider** | ドライバー別平均 | name, expectedLapTime(秒), defaultFuelRate, color |
| **Stint** | スティントブロック | stintNumber, riderId, refuelL(給油後残量), plannedLaps, startedAt/endedAt |
| **ActualLap** | ラップ明細の1行 | lapNumber(通算), lapTimeSec(0.001精度), condition(D/W/SC/EX), outIn(OUT/IN), fuelUsedL |
| FuelType / Segment | 計画側（Phase 3で活用） | 燃料タイプ・区間割当 |

### 2-2. 燃料・ペース計算（`src/lib/race-calc.ts`）

すべて DB 非依存の純関数。

**① 1周の燃料使用量** `fuelForLap`
```
明示のfuelUsedLがあれば優先。
OUT/IN周      → fuelRateOutIn (既定 0.33)
通常周(路面別) → Dry:0.35 / Wet:0.32 / SC:0.27
```

**② スティントの燃料推移** `computeStintState`
```
残燃料 = 給油量(refuelL) − Σ(各周の使用量)         … スティント先頭から順に積算
可能Lap数 = 残燃料 ÷ (直近路面の通常周消費)          … ＝Excelの「可能Lap数」
```

**③ ペース指標**
```
直近3周平均  recentGreenAverage … OUT/IN・SCを除いた直近3周の平均（今のペース）
路面別平均    averageByCondition … D/W別の平均ラップ
```

**④ レースクロック** `raceClock`
```
経過 = now − startedAt
残り = レース時間(420分) − 経過
```

**⑤ 着地予測・残ピット** `projectRace`（**前方シミュレーション**）
```
残り時間を、1周ずつ avgLap で消費しながらシミュレート。
スティント上限に達したら pitLossSec(240秒) を消費してピット＝残ガス満タン扱いで継続。
 → projectedTotalLaps（着地周回）
 → remainingPits（残りピット回数）
 → lapsUntilNextPit = min(可能Lap数, maxStintLap − 現スティント周回)
 → nextPitInSec = lapsUntilNextPit × avgLap
avgLap は「直近3周平均 → ドライ平均 → 想定Lap」の順でフォールバック
```

**⑥ 対予定（貯金/借金）** `scheduleBank`
```
Σ(想定Lap − 実績Lap)  （通常周のみ）
＋ = 予定より速い(貯金) / − = 遅い(借金)
```

### 2-3. 画面と表示

**ライブ入力 `/live`**（本番の入力＆判断画面）
- 入力: **分＋秒（秒は小数=0.001秒精度）**／路面(ドライ/ウェット/SC)／OUT・IN／走者。直前周コピー・直前取消。
- ピットイン: 給油量と次走者を指定 → 新スティント開始（残燃料が給油量にリセット）
- タイル: 残燃料 / 可能Lap数 / **次ピットまで** / 直近3周平均 / 残り時間 / **着地予測（残ピット）**

**ダッシュボード `/`**
- 燃料残量・通算周回・現走者・残り時間
- 着地予測 / 次ピットまで / 残ピット回数 / 対予定（貯金/借金）
- **計画 vs 実績チャート**（実績ラップの推移＋想定タイムの基準線。ピット周は除外）
- ドライ平均 / ウェット平均 / 直近3周平均

**設定 `/settings`**
- レース設定（時間・コース長・タンク・**路面別燃費**・**想定タイム各種**）
- ドライバー管理（名前・想定Lap・色）

## 3. Excel → アプリ 対応表（要約）

| Excelでやっていたこと | アプリでの実装 |
|---|---|
| ラップを分＋秒(1/1000)で手入力 | `/live` の分＋秒フィールド（秒は小数入力）→ 秒Floatで保存 |
| 路面(D/W/SC)・OUT/INのタグ付け | ワンタップのトグル |
| 残ガス・可能Lap数の自動計算 | `computeStintState`（残燃料・可能Lap数）をタイルで即時表示 |
| スティント＝給油〜給油の区切り | `Stint`モデル＋「ピットイン」操作で新スティント開始・給油リセット |
| 残り時間・残りPit回数・着地周回 | `raceClock`＋`projectRace`（前方シミュ） |
| 直近3周平均・路面別平均 | `recentGreenAverage`／`averageByCondition` |
| 計画 vs 実績 | 想定タイムを基準線にした実績推移チャート＋対予定(貯金/借金) |
| 想定各タイム・燃費の設定 | `/settings` で編集 |
